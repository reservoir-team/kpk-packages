# kpk-packages

Package index and release binaries for `kpk` (Kalahari Package Keeper),
the package manager for [Kalahari Linux](https://github.com/reservoir-team/kalahari-linux).

Packages are built and published automatically by a scheduled GitHub Actions
workflow. Each package is a `.kpk.tar.zst` archive attached to a GitHub
Release, indexed in `index.json`.

See the main [kalahari-linux](https://github.com/reservoir-team/kalahari-linux)
repo for `kpk` itself and the package format spec.
